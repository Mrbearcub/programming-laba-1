Top-down shooter прототип


# Структура папок

- Assets
	-Bullets
	-Enemy
	-Objects
-Scripts (все скрипты)
-grass.tscn (основная сцена)


# Содержание сцен

- Сцена уровня (grass.tscn):
	- содержит спрайт травы (Grass_sprite)
	- ограничена коллизией (Area2D и его дочерние компоненты)
	- содержит скрипт уровня (grass.gd):
		- вызывает сцену игрока (player.tscn) при запуске игры
		- спавнит врагов


- Сцена игрока (player.tscn):
	- содержит спрайт (Sprite2D)
	- содержит таймер (Timer)
	- содержит хпбар (HealthBar)
	- содержит скрипт игрока (player.gd):
		- отвечает за передвижение игрока
		- позволяет выйти из игры
		- отвечает за стрельбу, посредством вызова сцены пули (bullet.tscn). Имеет таймер перезарядки
		- имеет функцию (TakeDamage) отвечающую за получение урона (уменьшение хп бара)

### Пули

- Сцена пули (bullet.tscn):
	- имеет коллизию
	- содержит скрипт пули (bullet.gd):
		- отвечает за позицию пули и ее скорость полета
		- наносит урон врагам и объектам
		- уничтожает пулю при выходе за экран

- Сцена пули врага (enemy_bullet.tscn):
	- имеет коллизию
	- содержит скрипт пули (bullet.gd):
		- отвечает за позицию пули и ее скорость полета
		- наносит урон игроку
		- уничтожает пулю при выходе за экран

### Враги

- Класс Enemy (enemy.gd):
	- задает наличие хп
	- позволяет получать урон (функция TakeDamage)
	- уничтожает при смерти

- Сцена быстрого врага (fast_enemy.tscn):
	- содержит спрайт (Sprite2D)
	- имеет зону урона (DamageArea)
	- содержит скрипт (fast_enemy.gd):
		- класс Enemy
		- отвечает за передвижение врага и направление его движения
		- при соприкосновении с игроком наносит урон

- Сцена стреляющего врага (shooter_enemy.tscn):
	- содержит спрайт (Sprite2D)
	- имеет зону (Area2D)
	- имеет маркер для появления пуль (Marker2D)
	- имеет таймер для перезарядки (ShootTimer)
	- содержит скрипт (shooter_enemy.gd):
		- класс Enemy
		- отвечает за передвижение врага и направление его движения
		- выпускает пули (enemy_bullet.tscn) с определенным интервалом

### Объекты

- Сцена бочки (barrel.tscn):
	- содержит спрайт (Sprite2D)
	- имеет коллизию
	- содержит скрипт (barrel.gd):
		- отвечает за хп бочки
		- получение урона от пуль

- Сцена шипов(spikes.tscn):
	- содержит спрайт (Sprite2D)
	- имеет коллизию
	- содержит скрипт (spikes.gd):
		- наносит урон игроку
